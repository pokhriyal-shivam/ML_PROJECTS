#  AQI Prediction using Deep Learning (PyTorch)


## Overvie
A Deep Learning based Air Quality Index prediction system built using PyTorch.

The model predicts AQI values using environmental factors such as:

- PM2.5
- PM10
- NO2
- SO2
- CO
- Ozone
- Date information

## Tech Stack
- Python
- PyTorch
- Streamlit
- Pandas
- NumPy
- Scikit-learn


## Model Architecture
Neural Network:

Input Layer:
11 Features

Hidden Layers:

128 → 64 → 32

Output:

AQI Prediction

 Deep Learning Regression Model

 Real-time AQI Prediction
