# Customer Churn Prediction

An end-to-end Machine Learning project that predicts customer churn using the Telco Customer Churn dataset.

## Project Overview

This project analyzes customer behavior and predicts whether a customer is likely to leave the telecom service.

## Machine Learning Workflow

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Feature Engineering
* One-Hot Encoding
* Feature Scaling
* Model Training
* Hyperparameter Tuning using GridSearchCV
* ROC-AUC Evaluation
* Threshold Tuning
* Streamlit Deployment

## Model Performance

* Accuracy: 78.9%
* ROC-AUC Score: 0.83
* Model: Logistic Regression
